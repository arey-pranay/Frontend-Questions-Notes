# CSS `position`: `static` vs `relative` vs `absolute` vs `fixed` vs `sticky`

## Key Idea

The `position` property controls **how an element is placed in the document** and whether it participates in normal layout flow.

A **positioned element** is one whose `position` is `relative`, `absolute`, `fixed`, or `sticky`.

| `position` | In normal flow? | Positioned relative to                              | Scrolls with page? |
| ---------- | --------------- | --------------------------------------------------- | ------------------ |
| `static`   | ✅ Yes           | Normal flow                                         | ✅ Yes              |
| `relative` | ✅ Yes           | **Itself**                                          | ✅ Yes              |
| `absolute` | ❌ No            | Closest positioned ancestor                         | ✅ Yes              |
| `fixed`    | ❌ No            | Viewport                                            | ❌ No               |
| `sticky`   | ✅ Initially     | Its normal position → scrolling container threshold | Partially          |

---

## 1. `static` — Default

```css
.box {
  position: static;
}
```

* Default positioning.
* Element participates normally in document flow.
* `top`, `right`, `bottom`, `left` **do not apply**.
* `z-index` does not apply in the normal positioned-element sense.

```css
.box {
  top: 20px; /* ignored */
}
```

Think: **"Just follow the normal layout."**

---

## 2. `relative` — Move From Its Normal Position

```css
.box {
  position: relative;
  top: 20px;
  left: 10px;
}
```

The element is shifted **relative to where it would normally be**.

Important:

* It **remains in normal flow**.
* Its original space is preserved.
* Other elements behave as if it were still in its original position.

```text
Normal:       A [B] C

relative:     A    [B]
                   ↓
                   C
```

The gap left behind is still there.

### Common use

A very common pattern is:

```css
.parent {
  position: relative;
}

.child {
  position: absolute;
}
```

The parent doesn't necessarily need to move; `relative` establishes a **positioning context** for the absolute child.

---

## 3. `absolute` — Remove From Flow

```css
.child {
  position: absolute;
  top: 0;
  right: 0;
}
```

The element:

* Is **removed from normal flow**.
* Does not reserve its normal space.
* Does not affect the position of surrounding elements.
* Is positioned relative to its **closest ancestor that establishes a containing block**, commonly an ancestor with `position: relative/absolute/fixed/sticky`.
* If there is no suitable ancestor, it is positioned relative to the initial containing block.

Example:

```css
.card {
  position: relative;
}

.badge {
  position: absolute;
  top: 10px;
  right: 10px;
}
```

```text
┌──────────────────────┐
│                BADGE │
│                      │
│       CARD           │
│                      │
└──────────────────────┘
```

### Important interview point

`absolute` does **not** automatically mean "relative to the parent."

It means relative to the **nearest appropriate containing block**, often created by a positioned ancestor.

---

## 4. `fixed` — Fixed to the Viewport

```css
.button {
  position: fixed;
  bottom: 20px;
  right: 20px;
}
```

The element:

* Is removed from normal flow.
* Is positioned relative to the **viewport** in the common case.
* Doesn't move when the page is scrolled.

Typical uses:

* Floating action button
* Chat button
* Fixed navbar
* Cookie banner
* Back-to-top button

```text
┌──────────────────────┐
│                      │
│      Page content    │
│                      │
│                  ●   │ ← fixed
└──────────────────────┘
```

### Interview nuance

Although `fixed` is generally viewport-relative, certain ancestor properties such as `transform` can establish a different containing block. So **"always viewport" is a useful rule of thumb, not an absolute CSS rule.**

---

## 5. `sticky` — Relative → Stuck

```css
.header {
  position: sticky;
  top: 0;
}
```

`sticky` behaves like `relative` **until a scrolling threshold is reached**.

Then it becomes "stuck" within its scrolling container.

Example:

```text
Before scrolling:

┌──────────────────┐
│ Header           │ ← normal position
├──────────────────┤
│ Content          │
│ Content          │
│ Content          │
└──────────────────┘


After scrolling:

┌──────────────────┐
│ Header           │ ← stuck at top
├──────────────────┤
│ Content          │
│ Content          │
│ Content          │
└──────────────────┘
```

```css
.header {
  position: sticky;
  top: 0;
}
```

Without an inset such as `top`, `bottom`, etc., there is usually **no threshold at which the sticky behavior becomes noticeable**.

### Common uses

* Sticky navbar
* Section headings
* Table headers
* Sidebar navigation

---

# The Most Important Differences

### `relative` vs `absolute`

**Relative:**

```css
position: relative;
```

→ stays in flow
→ moves from its original position
→ original space remains

**Absolute:**

```css
position: absolute;
```

→ removed from flow
→ doesn't reserve space
→ positioned against a containing block

---

### `absolute` vs `fixed`

**Absolute**

→ anchored to a containing block
→ scrolls with the page

**Fixed**

→ generally anchored to viewport
→ stays in place while scrolling

---

### `relative` vs `sticky`

**Relative**

→ simply stays in flow and can be offset

**Sticky**

→ starts behaving like relative
→ sticks when scrolling reaches its threshold
→ constrained by its scrolling/container boundaries

---

## Interview Mental Model

```text
static
  ↓
Normal document flow

relative
  ↓
Normal flow + visually offset

absolute
  ↓
Removed from flow + positioned

fixed
  ↓
Removed from flow + viewport/container anchored

sticky
  ↓
Normal flow → sticks at scroll threshold
```

### TL;DR

> **Static** = normal layout
> **Relative** = normal layout + move from itself
> **Absolute** = removed from flow + positioned relative to a containing block
> **Fixed** = removed from flow + stays anchored while scrolling
> **Sticky** = relative until a scroll threshold, then sticks
