# `display`: block vs inline-block vs inline

The `display` property controls **how an element participates in layout**.

| Property               | `block`                                 | `inline-block`                           | `inline`                                                                                                    |
| ---------------------- | --------------------------------------- | ---------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Width**              | Fills available parent width by default | Shrinks to content                       | Shrinks to content                                                                                          |
| **New line?**          | ✅ Yes                                   | ❌ No                                     | ❌ No                                                                                                        |
| **`width` / `height`** | ✅ Yes                                   | ✅ Yes                                    | ❌ Ignored                                                                                                   |
| **`vertical-align`**   | ❌ No                                    | ✅ Yes                                    | ✅ Yes                                                                                                       |
| **Padding**            | All sides affect layout                 | All sides affect layout                  | Horizontal affects layout; vertical can visually render but doesn't properly affect surrounding line layout |
| **Margin**             | All sides affect layout                 | All sides affect layout                  | Horizontal affects layout; vertical doesn't affect layout                                                   |
| **Floated**            | —                                       | —                                        | Becomes block-level-like, allowing dimensions/margins/padding                                               |
| **Typical usage**      | Layout/sections                         | Sized elements that should remain inline | Text-level content                                                                                          |

### `block`

```css
display: block;
```

* Starts on a **new line**.
* Normally occupies the available width.
* Multiple block elements stack vertically.

Examples: `<div>`, `<p>`, `<section>`.

### `inline-block`

```css
display: inline-block;
```

* Sits **beside other inline/inline-block elements**.
* Still allows `width`, `height`, and all margins/paddings to affect layout.
* Useful when you want an element to behave like an inline item but have explicit dimensions.

Examples: buttons, custom-sized form controls, images.

### `inline`

```css
display: inline;
```

* Flows with surrounding text.
* `width` and `height` don't apply.
* Vertical margin doesn't affect layout.
* Its layout is primarily controlled by the **line box / `line-height`**.

Examples: `<span>`, `<a>`, `<b>`, `<i>`.

### Interview Traps

**1. `inline` doesn't mean "no padding/border".**

An inline element can have padding and borders, but **vertical padding/border doesn't increase the line's layout height in the same straightforward way a block/inline-block element does**. This can cause overlapping or surprising visuals.

**2. `inline-block` is often the middle ground.**

Think:

> **block = box on its own line**
> **inline-block = box that can sit in a line**
> **inline = text-like content**

**3. Modern layouts**

For actual page layouts, prefer **Flexbox/Grid** over using `inline-block` or `float` as a layout system. `inline-block` is still useful for small inline components and text-flow situations.

**4. Whitespace matters**

Inline and inline-block elements participate in inline formatting, so whitespace/newlines in HTML can create visible gaps between `inline-block` elements.

### TL;DR

```text
block        → new line + controllable dimensions
inline-block → same line + controllable dimensions
inline       → same line + text-like; no width/height
```
