There are 2 functions inside `.then()` — one for success and one for failure.

js
```
const cached = new Map();

Promise.resolve(cached)
  .then(
    () => {
      console.log("rendering");
      throw new Error("render failed");
    },
    () => console.log("onError")
  )
  .catch(() => console.log("caught"));
```

### How it works

`.then(onFulfilled, onRejected)` accepts two callback functions:

1. First function (`onFulfilled`) — runs when the promise is fulfilled.
   - Logs `"rendering"`.
   - Throws an error, making the promise returned by `.then()` rejected.
2. Second function (`onRejected`) — runs when the original promise is rejected.
   - It does not run here because `Promise.resolve(cached)` is fulfilled.
3. `.catch()` — handles the error thrown by the first function.
   - Logs `"caught"`.

### Output

```
rendering
caught
```

Key takeaway: The second function in `.then()` handles rejection of the previous promise, not errors thrown by the first function in the same `.then()` call. Those errors can be caught by the next `.catch()`.
